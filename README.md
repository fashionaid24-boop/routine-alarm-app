# 오늘의 루틴

하루 루틴을 간단하게 기록하고, 완료 현황을 한눈에 확인하는 반응형 웹 앱입니다.

## 주요 기능

- 루틴 추가: 이름, 시간, 색상, 메모 입력
- 완료/미완료 및 전체 필터
- 오늘의 완료 수, 달성률, 진행률 표시
- 브라우저 알림 권한 요청
- 주간 달력과 오늘 날짜 표시
- `localStorage` 기반 데이터 저장
- 모바일 반응형 화면

## 실행

별도의 빌드 과정 없이 `index.html`을 브라우저로 열면 사용할 수 있습니다. 브라우저 알림은 HTTPS 또는 localhost 환경에서 동작합니다.
